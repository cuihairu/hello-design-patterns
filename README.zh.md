## 开发

本站使用 [VitePress](https://vitepress.dev/) 构建。[VitePress 侧栏](./docs/.vitepress/config.mts)是唯一权威导航源；新增或移动页面时更新侧栏，不另维护手写页面清单。`npm run docs:audit` 核对侧栏、站内链接、页面标题与各分区索引是否与磁盘文件一致；`npm run docs:build` 兜底死链。
