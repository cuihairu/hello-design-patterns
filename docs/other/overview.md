# 其他模式

还有一些常见，但不好分类的模式

这些模式广泛应用于分层架构、数据访问和状态管理等场景，虽然不太好归入经典三类，但在工程实践中同样重要。

### 本目录包含的模式

- [MVC 模式](/other/mvc)：把应用程序拆分为模型、视图、控制器，实现关注点分离。
- [MVVM 模式](/other/mvvm)：在 MVC 基础上引入 ViewModel，通过数据绑定分离视图与业务逻辑。
- [对象-关系映射（ORM）模式](/other/orm)：把数据库表映射为对象，用面向对象方式操作数据库。
- [事件溯源模式](/other/event-sourcing)：记录状态变化事件而非最终状态，以此重建状态并支持审计回溯。
- [事务脚本模式](/other/transaction-script)：把一个业务操作写成线性处理函数，规则跟流程走，与[贫血模型](/anti-patterns/anemic-domain-model)互为对照。
